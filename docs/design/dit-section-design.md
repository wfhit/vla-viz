## 0. 一句话定位

k005b 的动作专家是一个 **DiT**：一个以时间 t 为条件、用 adaLN 调制的 Transformer。它有 28 个块，每块的结构是
`AdaRMSNorm(x; te) → 注意力 → ⊕ → AdaRMSNorm(x; te) → SwiGLU MLP → ⊕`。

它和普通 DiT 有两点不同：

- **注意力不是自注意力，而是联合注意力。** 第 i 个 DiT 块的 Q 来自 17 个后缀 token，K/V 是「主干第 i 层的前缀 K/V ‖ 后缀自己的 K/V」。
- **它被调用 10 次。** 每次是一个 Euler 步，t 依次为 1.0、0.9、…、0.1。主干只跑 1 次。

场景要让观众一眼看出三件事：

1. 主干和 DiT 是两个 28 层的 Transformer，**逐层配对**。
2. 每对之间唯一的接口，是同一张联合注意力矩阵。
3. 解码 = 主干 1 次 + DiT 10 次。

## 1. 场景整体结构

### 1.1 层对 = 一个"传送门"，内有两条泳道

28 个层对单列竖向对叠（不分两列）：每个层对 = 主干层 i 与专家层 i 左右并排，层对头标注 "Layer pair i: trunk Li <-> expert Ei"，两塔标题放在列的左右两侧（仅总览/D0 显示）。每个层对就是一个传送门，门内左右两条泳道，**共用同一个 y 行**：

| 泳道 | 宽度（token 轴） | 内容 | 颜色 |
|---|---|---|---|
| 主干泳道 | 32 列（1240 个前缀 token 中的真实窗口） | RMSNorm → Q/K/V → 注意力 → o_proj → ⊕ → RMSNorm → MLP → ⊕ | 绿 |
| DiT 泳道 | 17 列（状态 1 + 动作 16） | AdaRMSNorm → Q/K/V → 注意力 → o_proj → ⊕ → AdaRMSNorm → MLP → ⊕ | 橙 |

画法规则：

- DiT 的每个子层块都**紧贴**主干同名子层块的右侧，缝宽 1 格，同一高度、同一深度。
- 这样观众读到的是「同一个子层，处理的是一条 1240 + 17 的拼接序列；其中 17 列由另一套权重（专家权重）计算」。这正是 `_layer_pair` 的真实结构。
- 场景里不再有独立的专家列，不再有与层堆无关的竖线。

### 1.2 两流耦合：画在联合注意力矩阵本身

每个头的注意力矩阵画成完整的 **(32 + 17) × (32 + 17) 联合矩阵**：x 轴是 key，y 轴是 query。它分成四个象限：

```
               key: 前缀窗口(32)      key: 后缀(17)
query 前缀   [ 主干因果注意力       |   空（掩码：前缀看不到后缀） ]
query 后缀   [ 耦合区 scP           |   DiT 自注意力 scS          ]
```

- **左下象限 scP 就是耦合**，即 DiT 的 Q 读主干的 K。耦合线从主干第 i 层各 KV 组的 K 块（前缀部分）指向本层各头的 scP，V 块指向后缀的头输出 voT。
- 耦合线的显示规则：所有可见层都画淡线，当前层加亮，线宽正比于真实的「后缀注意力落在前缀上的质量」。
- **右上象限故意留空**，用来表达 `build_fused_mask` 的单向性。旁边配 ASCII 标签 `prefix cannot see suffix`。
- softmax 后的概率矩阵采用同样的四象限画法。

### 1.3 时间条件：一条"时间总线"

DiT 和普通 Transformer 的关键区别是 adaLN，所以 t 必须有可见的入口：

- **位置与内容**：DiT 泳道最右侧有一根竖向的时间总线。顶端是 `t → te(t)` 块（sincos 768 维，显示前 64 维）。
- **每层的分支**：总线在每个层对伸出两个短分支，进入 γ₁β₁、γ₂β₂ 窄块，再分别指向该层的两个 AdaRMSNorm。窄块使用真值 `E{i}.ada`。
- **终点**：专家最终的 norm 是普通 RMSNorm，所以总线在第 27 层结束。
- **每步的变化**：t 每走一步，总线顶端的 t 值改变，28 层的 γβ 窄块随之整体换色。

### 1.4 输入与输出

| 端点 | 主干 | DiT |
|---|---|---|
| 顶部输入 | 输入嵌入（前缀 token 流） | 后缀输入，紧贴前缀嵌入右侧。由 `state75 → state_proj`（token 0）和 `x_t → action_in_proj ⊕ te → time_mlp`（token 1..16）拼成 |
| 底部输出 | ln_f → **h\***（边界 token）→ knack / done 头 | 专家 final RMSNorm → 丢掉 token 0 → action_out_proj → **v**（16×23） |

### 1.5 Euler 轨迹带（解码专用）

在 DiT 输入一侧放一条横排的 11 块 16×23 板：`x_1.0, x_0.9, …, x_0.1, x_0`。

- 第 k 次穿行读板 k，写板 k+1。写入要经过一个 `⊖ 0.1·v` 节点，节点的两个输入是板 k 和 v_k。
- 唯一的回程箭头从 v_k 出发，沿时间总线外侧上行，到达 ⊖ 节点。它带标签 `Euler: x - 0.1*v`，起点和终点都是块。
- 最后一块板 x_0 就是动作块，接到柱场和机器人章节。

### 1.6 箭头原则（沿用并收紧）

- 每根箭头有可见的起点块和终点块。不得有孤悬或装饰箭头，也不得穿块。
- 一个主干块 + 它的 DiT 尾块视为一个**单元**：箭头连单元的外框，从而不穿过尾块。
- 残差的 skip 用 ⊕ 块上的字标表示，不画绕行线。
- 一次前向时，从上一层 ⊕ 单元到下一层 norm 单元只画**一根**箭头。它就是拼接序列这条流，不再画左右两根。

## 2. 分镜 A：一次前向（拼接 → 逐层穿行 → h*）

此路径对应训练时的联合前向（`forward`，`fused_behavior_action.py:388-442`），在 t=1 时与解码第 0 步数值一致。

| 镜 | 场景动作 | 箭头 / 点亮 | 显示的真值 |
|---|---|---|---|
| A1 拼接 | 镜头停在顶部：前缀嵌入（绿）和后缀输入（橙）并排，合成一条 1257 长的序列 | 后缀的三条输入链依次点亮，落入后缀输入块 | `embed_out` 窗口、`expert_in`、`state75`、`x1`、`te(1)` |
| A2 进入第 0 层 | 一根单元箭头从输入单元进入第 0 层的 norm 单元 | 主干 RMSNorm 和 DiT AdaRMSNorm 同时点亮；时间总线分支 γ₁β₁ 点亮 | `L0.ln1_out`、`E0.ln1`、`E0.ada` |
| A3 Q/K/V | 主干 Q/K/V 与 DiT 的 qT/kT/vT 一起点亮 | norm 单元 → Q/K/V 单元 | `L0.q/k/v` 与 `E0.q/k/v`（逐头） |
| A4 联合注意力 | 四象限矩阵点亮，右上象限保持空，耦合线加亮 | K 单元 → 矩阵单元，Q 单元 → 矩阵单元，耦合线 K→scP | `attn_scores`、`E0.scp/scs`；质量条（视觉 / 文本 / 后缀，状态列与答案列画叉） |
| A5 softmax·V → o_proj → ⊕ | 两条泳道并行完成 | 矩阵 → 头输出 → o_proj → ⊕ | `attn_probs`、`E0.pp/ps`、`E0.vo`、`E0.o`、`E0.res1` |
| A6 MLP → ⊕ | 第二个 AdaRMSNorm 受 γ₂β₂ 调制，然后 MLP | ⊕ → norm → gate/up → act → down → ⊕ | `E0.ada`（行 2–3）、`E0.gate/up/act/mlp/out` 及主干对应量 |
| A7 穿过 28 层 | 镜头沿层堆下移，每层 11 个子阶段依次点亮（现有 FlowPass 节奏），未到达的块留空 | 逐层的单元箭头点亮 | 每层真值；当前层的耦合线和质量条随层变化 |
| A8 两个出口 | 主干出口：ln_f → h\* → knack / done。DiT 出口：final norm → v → `x1 − v` | 各自的出口箭头 | `h_star`、`knack_probs`、`done_probs`、`expert_out`、`action_velocity`、`action_chunk` |

## 3. 分镜 B：flow matching 解码（噪声 → 10 次 DiT 穿行 → 动作块）

此路径对应部署时的 `sample_action_chunk`（`fused_behavior_action.py:526-550`）。

| 镜 | 场景动作 | 显示的真值 |
|---|---|---|
| B1 前缀只算一次 | 主干泳道完整穿行一次（快放）。之后每层主干的 K/V 块变成「缓存」样式（描边、半透明），其余主干块淡出 | `encode_prefix` 等价量；断言 `prefix_kv_max_abs_diff_across_seeds = 0` |
| B2 起点 | 轨迹带的板 0 = 噪声 x_1，时间总线显示 t = 1.0 | `fm.steps[0].x`、`te(1.0)` |
| B3 第 k 次穿行（k = 0…9） | ① 板 k 经输入链变成后缀输入。② 时间总线的 t 换成 t_k，28 层的 γβ 窄块整体换色。③ **只有 DiT 泳道**从第 0 层穿到第 27 层，每层的联合注意力从缓存的 K/V 读数，耦合线逐层加亮。④ 底部得到 v_k。⑤ 回程箭头经过 ⊖ 节点写入板 k+1 | `t_k`、`te(t_k)`、`E{i}.ada`(t_k)、`expert_in`(k)、每层 `ln1/o/res1/ln2/mlp/out`(k)、每层头均注意力与质量(k)、`v_k`、`x_{k+1}`、`‖v_k‖`、`MSE(x_{k+1}, a)` |
| B4 节奏 | 第 0 次穿行慢放，逐子层讲解（同 A7）。第 1、2 次中速。第 3–9 次快放，只点亮每层的 ⊕ 与耦合线。播放条每完成一步走一格 | 同上 |
| B5 出块 | 板 10 = x_0 → 动作块 16×23 → 柱场 → 机器人章节 | `action_chunk`（K=10）、与标签 a 对比 |

关于时间条件，要讲清两点：

- **主干输入在 10 次中完全相同**，所以 knack / done 逐位不变。
- **DiT 每次只换两样东西**：输入板 x_t，和总线上的 t。
